# 🚀 START HERE - Quick Guide

## "Nothing is Extracting" - Here's the Fix! ⚡

### The #1 Most Common Issue:

**You need to REFRESH the page after installing the extension!**

---

## ✅ 3-Step Fix

### Step 1: Reload Extension
```
Go to: chrome://extensions/
Find: "Advanced Lead Generator Pro"
Click: The reload icon (🔄)
```

### Step 2: Refresh Your Webpage
```
Go to the webpage where you want to extract leads
Press: F5 (or Ctrl+R / Cmd+R)
Wait: For page to fully load
```

### Step 3: Extract!
```
Click: Extension icon in toolbar
Click: "Extract Leads from Page"
Wait: 1-2 seconds
Done: See results!
```
